## About FrameCore

Professional framing app for Android, built for Hispanic wood framers: born in Idaho, made for framers wherever they frame.

- 13 field calculators (rafters, headers, studs, stairs, OC layout and more), with the wall cut list to PDF
- The code in your language, with the why (nailing schedules, header tables)
- Pre-inspection checklist — 29 items across 7 categories
- Plan viewer with Plan Intelligence
- Manual with 112 articles, a 232-term glossary and 130 pro tips, in jobsite Spanish with the trade terms in English
- 100% offline

## Repository Scope

This repository contains **only** the public web presence for FrameCore:

- Redirects to loomframing.com (`loom/`)
- Privacy policy (required by Google Play)
- Marketing assets (screenshots, guides)
- Standard CI/CD and security workflows

Source code for the app itself is maintained in a separate private repository.
